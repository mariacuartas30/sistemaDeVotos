# Sistema de Votación

Sistema de votación desarrollado en Python utilizando Git y GitHub para aplicar control de versiones y trabajo con ramas.

## Funciones

### 1. Registrar voto
Permite registrar el voto de una persona utilizando un diccionario y evita que una misma persona vote más de una vez.

Responsable: Salo

### 2. Ver resultados
Muestra la cantidad de votos obtenidos por cada candidato y calcula el porcentaje correspondiente.

Responsable: Salo

### 3. Reiniciar votación
Guarda los resultados de la votación en un archivo de historial y permite iniciar una nueva votación.

Responsable: Johan

## Mejora adicional

Se agregó un menú principal para facilitar el uso del sistema y una función que permite mostrar el candidato ganador.

También se controla el caso de empate entre candidatos.

## Tecnologías utilizadas

- Python
- Git
- GitHub

## Ramas

- `registro`: registro y validación de votos.
- `resultados`: resultados y porcentajes.
- `reinicio`: reinicio y almacenamiento del historial.
- `main`: versión integrada del proyecto.
